# 게임 메뉴 순서 (`game-list-order`)

### 요청 프롬프트

> 게임 메뉴 순서를 마니또 미션을 1번으로 바꿔

### 구현 결정

- 홈 화면 게임 목록의 순서는 `games/registry.ts` 의 `games` 배열 순서이므로 거기서만 바꿨다(레지스트리가 SSOT). 순서는 마니또 미션 → 번호 뽑기 → 노래 맞추기 → 인물 맞추기이다.
- 라우트와 사회자 메뉴의 관리 패널도 같은 배열을 쓰므로 패널 순서는 목록 순서를 따른다. 화면 코드와 URL 은 바뀌지 않는다.
