# 인물 맞추기 (person-quiz)

## 2026-11-12 — 게임 신규 추가

### 요청 프롬프트

> 레크리에이션용 '인물 맞추기' 진행자 게임 개발. 진행자(사회자)가 화면을 띄워두고 참여자들과 함께 진행. 12제자(베드로·안드레·야고보·요한·빌립·바돌로매·도마·마태·야고보·다대오·시몬·가룟 유다) 카드 메뉴 → 제자별 10문항(사진 큼직하게, n/10, 이전/이름 공개·가리기/다음/메인으로) → 10장 후 게임 종료 안내 → 결과 확인(10장 썸네일+정답 그리드, 목록으로 돌아가기). 결과 확인한 제자 카드는 표시. 120장(12×10) 풀을 [전체 데이터 리셋(셔플)]로 Fisher-Yates 재분배. 단축키 Space/→(Enter)/←/Esc. 이미지는 로컬 경로 JSON 구조, 이미지가 없어도 fallback. 프로젝터용 다크 모드, 큰 굵은 이름 텍스트.

(원문 전체는 사용자 요청 메시지 참고. 요약본)

### 구현 결정

- **규칙 준수**: 프로젝트 규칙에 맞춰 Next.js 단일 클라이언트 게임(`games/person-quiz/`)으로 만들었다. 백엔드 없이 `localStorage`에 진행 상태를 저장하며, 새로고침해도 이어진다.
- **사회자 로그인**: 정답이 노출되지 않도록 노래 맞추기와 같이 사회자 비밀번호 뒤에서만 진행한다.
- **그룹/단계**: 제자 한 명 = 사진 10장 묶음. 단계는 `quiz → end → results`. 결과 확인 버튼을 누르면 `checked`가 되어 메인 카드에 ✅ 표시. 메인에서 다시 들어가면 마지막 단계에서 이어진다.
- **리셋**: 120장 id를 Fisher-Yates로 섞어 10장씩 12그룹에 재분배하고 진행·확인 표시를 모두 지운다. 실수 방지로 한 번 더 확인한다. 처음(저장 전) 배정은 데이터 순서대로(무작위 없음 → 서버/클라이언트 일치).
- **같은 이름의 야고보 2명**: 카드에 보조 설명(세베대의 아들 / 알패오의 아들)을 붙여 구분했다.
- **이미지**: `data/people.json`에 `image` 경로를 두고 `public/games/person-quiz/images/person_001.jpg`~`120`을 쓴다. 파일이 없으면 번호가 적힌 로컬 SVG 자리표시로 대체(인터넷·Unsplash 의존 없음).
- **인물 이름은 임시값**(`인물 001`…): 실제 인물/사진은 사용자가 채워야 한다.
- **단축키**: 버튼에 포커스가 있어도 Space/Enter가 이중 실행되지 않도록 keydown/keyup에서 처리했다.
