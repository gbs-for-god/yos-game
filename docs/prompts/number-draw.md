# 번호 뽑기 (`number-draw`)

## 2026-11-13 — 사회자만 접속할 수 있게 변경

### 요청 프롬프트

> 번호 뽑기 메뉴도 사회자만 접속할 수 있게 변경

### 구현 결정

- 노래 맞추기·인물 맞추기와 같은 방식을 썼다. `useVerifiedHostPin()` 으로 로그인 상태를 읽고, 로그아웃 상태에서는 `HostPinForm`(사회자 비밀번호 입력)만 보여 준다. 비밀번호는 `/host` 와 공유되는 탭 저장소를 쓰므로 탭에서 한 번만 입력하면 된다.
- 로그인 전에는 뽑기 화면(`NumberDrawBoard`)을 아예 렌더하지 않는다. 뽑기 상태(`useState`)는 안쪽 컴포넌트에 있어 로그인한 뒤에 만들어진다.
- 홈 화면의 게임 목록에는 계속 보이며, 게임 화면에 들어가면 비밀번호를 묻는다. 목록 카드 설명에 "사회자만 진행할 수 있어요"를 덧붙였다.
- 게임은 서버 상태가 없고 화면 접근만 막는 방식이다(다른 사회자 게임과 동일한 수준). 새 API·의존성은 없다.
