# K-pop 노래 맞추기 (`kpop-quiz`)

2008~2010년 K-pop 노래의 앞부분을 소리만 듣고 맞히는 게임. 사회자 노트북을 프로젝터에 띄워 진행한다. 서버 상태 없이 이 기기 안에서만 동작한다.

## 진행 방법

1. 사회자 비밀번호로 로그인한다 (로그인 전에는 곡 정보가 화면에 나오지 않는다. 비밀번호는 `/host`와 공유되어 탭에서 한 번만 입력하면 된다).
2. **앞부분 1초/3초 듣기**, **코러스 15초 듣기**, **전체 재생**으로 소리만 들려준다. 정답 공개 전에는 영상·썸네일·제목이 불투명 가리개로 완전히 덮여 있다.
3. **정답 공개**(Enter)를 누르면 가리개가 사라지고 가수·곡명과 앨범 커버(음원 영상)가 보인다.
4. **다음 곡**으로 넘어가면 다시 가려진다. **순서 섞기**로 곡 순서를 바꿀 수 있다.

단축키: `Space` 재생/정지 · `Enter` 정답 공개 · `←`/`→` 이전/다음 곡

## 파일

| 파일               | 역할                                                                       |
| ------------------ | -------------------------------------------------------------------------- |
| `data/songs.json`  | 곡 목록 (`id`, `title`, `artist`, `youtubeId`, `startTime`, `chorusStart`) |
| `logic.ts`         | 곡 이동·정답 공개·셔플·곡 목록 검증 (순수 함수)                            |
| `youtube.ts`       | YouTube IFrame API 로더와 최소 타입 (패키지 추가 없음)                     |
| `useSongPlayer.ts` | 플레이어 생성, 곡 변경 시 영상 준비, 재생/정지/구간 듣기                   |
| `Stage.tsx`        | 영상 영역 + 블라인드 가리개                                                |
| `Game.tsx`         | 사회자 로그인, 대시보드, 키보드 단축키                                     |

## 곡 추가·수정

- 기본 곡은 뮤직비디오가 아니라 **음원만 올라온 영상**("Provided to YouTube by …" 설명, 채널명 `아티스트 - Topic`)이다. 인트로 연출 없이 곡이 바로 시작되고 화면은 앨범 커버 한 장이다. 같은 곡의 라이브·리믹스·재발매 음원이 섞여 있으니 설명란의 앨범과 발매일(2008~2010)을 확인해서 고른다.
- `youtubeId` 는 영상 주소의 `v=` 뒤 11자리다. **임베드가 허용된 영상**이어야 한다 (뮤직비디오 중 외부 재생이 막힌 것이 있다).
  확인: `https://www.youtube.com/oembed?url=https://www.youtube.com/watch?v=<ID>&format=json` 이 200 이면 가능, 401 이면 임베드 금지, 404 면 없는 영상이다.
- 재생 중 오류가 나면 화면에 사유가 표시된다 (101·150 임베드 금지, 100 삭제/비공개). 그 곡은 다른 영상으로 바꾸거나 목록에서 뺀다.
- `chorusStart`(초)는 코러스(후렴) 시작 지점이다. **코러스 듣기** 버튼이 여기서부터 15초(`logic.ts`의 `CHORUS_SECONDS`)를 들려주고 멈춘다. 없는 곡은 버튼이 꺼진다. 기본값은 동기화 가사에서 반복되는 구간을 찾아 **추정한 값**이라 곡마다 직접 들어 보고 맞춰야 한다.
- `startTime`(초)은 인트로 정적이나 멘트를 건너뛰고 싶을 때 조절한다. 앞부분 N초 듣기는 이 지점부터 N초다.
- 곡 목록이 잘못되면(중복 id, 11자가 아닌 영상 ID 등) 게임 화면에 이유가 표시된다.
